## Shared notation and pipeline contract

For binary system \(j\), member \(k\in\{1,2\}\) has absolute magnitude \(x_{jk}=M_G\), dereddened colour \(C_{jk}=(G_{\rm BP}-G_{\rm RP})_0\), raw JCAPS metallicity \(\widehat z_{jk}\), and its reported uncorrected error \(\sigma_{z,jk}\). The system has one shared latent PARSEC metallicity \(Z_j=[M/H]\), evaluated on nodes \(Z_q\), \(q=1,\ldots,Q\). The saved first-stage object is \(\overline P_{jq}\), the posterior probability mass at node \(Z_q\), averaged over selected first-stage global posterior draws. The conditional grid weight \(P_{jq}(\boldsymbol\psi)\) is intermediate only and MUST NOT be treated as a saved second-stage input.

The pipeline is: (a) T8a samples global metallicity-calibration parameters and marginalizes each \(Z_j\) on the metallicity grid; (b) T8b evaluates a PARSEC-relative two-dimensional MLR surface and obtains member and total masses; (c) T8c evaluates the Rice-convolved dynamics likelihood through a mass-scale lookup and marginalizes it with \(\overline P_{jq}\).

The second stage MUST NOT multiply the JCAPS likelihood, CMD likelihood, population prior, or metallicity quadrature weights again. It MUST NOT feed dynamics back into T8a. In all documents, \(\log_{10}\) is the base-10 mass log in dex; an unqualified \(\log\) in likelihoods, softplus, or potentials is the natural log.

## Stage T8a: metallicity calibration and CMD posterior

The required input columns are exactly

\[
\widehat z_{j1}=\texttt{feh\_jcaps\_1},\quad
\widehat z_{j2}=\texttt{feh\_jcaps\_2},\quad
\sigma_{z,j1}=\texttt{jc\_sigma\_m\_h\_1},\quad
\sigma_{z,j2}=\texttt{jc\_sigma\_m\_h\_2}.
\]

If any is missing, the program MUST stop. It MUST NOT substitute fitted, calibrated, binary-corrected, or inflated metallicity columns.

The exact sampled global vector is \(\boldsymbol\psi=(\delta_z,s_C,\boldsymbol\omega)\). T6d \(b_G(x)\), \(s_z\), and \(\nu_z\) are plug-in quantities, not sampled in T8a. Conditional on \(Z_j,\boldsymbol\psi\), the two member measurements are independent:

\[
\widehat z_{jk}\mid Z_j,\boldsymbol\psi
\sim t_{\nu_z}\!\left(
Z_j+\delta_z+b_G(x_{jk}),
\sqrt{\sigma_{z,jk}^{2}+s_z^{2}}\right).
\]

The sign convention is \(\delta_z>0\Rightarrow\) JCAPS reports a higher value at fixed true \(Z_j\), relative \(b_G\), and scale. The current prior is \(\delta_z\sim\mathcal N(0,0.3^2)\) dex.

Current T6d plug-ins are

\[
\begin{aligned}
x\text{ knots}&=(3.5,6.0,8.5,11.0,13.5)\ {\rm mag},\\
b_G\text{ values}&=(0.1121285,0.0498776,0,-0.3103054,-0.5332039)\ {\rm dex},\\
s_z&=0.0464650\ {\rm dex},\qquad \nu_z=2.5236494,
\end{aligned}
\]

with linear interpolation and \(b_G(8.5)=0\). CMD uses \(\nu_C=4\), \(s_C\sim{\rm HalfNormal}(0.1\,{\rm mag})\), and PARSEC prediction \(C_{\rm P}(x,Z)\). Its formal colour error is

\[
\widehat\sigma_{C,jk}
=\frac{2.5}{\ln10}
\sqrt{{\rm SNR}_{\rm BP,jk}^{-2}+{\rm SNR}_{\rm RP,jk}^{-2}}.
\]

For an unmasked member, the CMD likelihood is

\[
L^{\rm CMD}_{jk}(Z\mid\boldsymbol\psi)
=t_{\nu_C}\!\left(
C_{jk}\mid C_{\rm P}(x_{jk},Z),
\sqrt{\widehat\sigma_{C,jk}^{2}+s_C^{2}}\right).
\]

The CMD colour zero point is fixed to zero; no extra colour-zero-point parameter is sampled.

The fixed full-grid CMD mask is

\[
m_{jk}=\mathbf1\!\left[
\min_{q\in\mathcal Q}T_{{\rm eff,P}}(x_{jk},Z_q)
\ge4000\ {\rm K}\right].
\]

The mask MUST be computed once over the full metallicity grid. Its value-based meaning is exact: \(m_{jk}=1\) includes the CMD likelihood at every \(Z_q\), whereas \(m_{jk}=0\) includes only the JCAPS likelihood and no CMD factor.

The current population prior has \(R=6\) truncated Gaussian bases over \(Z\in[-1.0,0.6]\) dex. Centers are equally spaced, each scale is \((0.6-(-1.0))/6\) dex, each basis is renormalized on the interval, and \(\boldsymbol\omega\sim{\rm Dirichlet}(1,\ldots,1)\). The current quadrature uses exactly 81 equally spaced \(Z_q\) nodes and trapezoid weights \(w_q^{(Z)}\). General implementations MUST record basis definitions, truncation normalization, grid, and weights.

For each global draw,

\[
\widetilde P_{jq}(\boldsymbol\psi)
=w_q^{(Z)}p_{\rm pop}(Z_q\mid\boldsymbol\omega)
\prod_{k=1}^{2}
L^{\rm spec}_{jk}(Z_q\mid\boldsymbol\psi)
\left[L^{\rm CMD}_{jk}(Z_q\mid\boldsymbol\psi)\right]^{m_{jk}},
\]

\[
P_{jq}(\boldsymbol\psi)
=\frac{\widetilde P_{jq}(\boldsymbol\psi)}
{\sum_{q'}\widetilde P_{jq'}(\boldsymbol\psi)}.
\]

The saved quantity is

\[
\overline P_{jq}
=\frac1{S_\psi}\sum_{d=1}^{S_\psi}
P_{jq}(\boldsymbol\psi^{(d)}).
\]

Here \(S_\psi\) is the actually selected draw count. Current behavior selects at most 128 draws without replacement using a recorded random seed. Metadata MUST record \(S_\psi\), seed, and selected indices or a digest. T8a does not sample \(Z_j\) in the final MLR MCMC.

Current PARSEC CMD construction uses \(9.3<\log_{10}({\rm age/yr})<10.0\), \(3<G_{\rm mag}<15\), and a 500-point \(3.5\le M_G\le13.5\) grid. In the source table, selected-age rows with the same \(G_{\rm mag}\) and fixed metallicity are averaged in colour and \(\log T_{\rm eff}\); this is source-table \(G_{\rm mag}\), not the later \(M_G\) evaluation grid. Colour uses an up-to-cubic smoothing spline with \(s=0.001\), \(\log T_{\rm eff}\) uses linear interpolation and is exponentiated, and runtime lookup is bilinear in \((M_G,Z)\). All these construction choices MUST be metadata.

Current coverage: 14,876 systems and 29,752 members; the 4000 K mask admits 12,167 members, 8,247 one-or-more systems, and 3,920 two-member systems. The historical 4730 K comparison is 6,627 members, 4,901 one-or-more systems, and 1,726 two-member systems. These are coverage diagnostics, not fitted results.

## Stage T8b: PARSEC-relative hard-monotone MLR

Define

\[
g_{\rm P}(x,Z)=\log_{10}[M_{\rm P}(x,Z)/M_\odot],\quad
g_{\rm P}^{*}(x,Z)=\sum_{ih}\Pi_{ih}B_i(x)C_h(Z),
\]

\[
\Delta_*(x,Z)=\sum_{ih}D_{ih}B_i(x)C_h(Z),\quad
g(x,Z)=g_{\rm P}^{*}(x,Z)+\Delta_*(x,Z).
\]

The reported correction to raw PARSEC is

\[
\epsilon_{\rm P}=g_{\rm P}^{*}-g_{\rm P},\qquad
\Delta_{\rm P}=g-g_{\rm P}=\Delta_*+\epsilon_{\rm P}.
\]

\(\Delta_*\) is the fitted computational correction to a fixed PARSEC spline projection; \(\Delta_{\rm P}\) is the scientific correction to raw PARSEC. The total-control coordinate \(\Theta_{ih}=\Pi_{ih}+D_{ih}\) is only the computational coordinate on which hard monotonicity is imposed. A diagnostic nearest monotone projection \(g_{\rm P,mono}\) MAY be computed for RMS/max-distance reporting, but MUST NOT replace ordinary fixed \(\Pi\), enter the likelihood, or change the constraint coordinate.

The shared tensor-product basis MUST specify nondecreasing knot vectors \(\boldsymbol\kappa_x,\boldsymbol\kappa_Z\), degrees \(d_x,d_Z\), domain, and boundary convention. \(B_i,C_h\) are nonnegative partition-of-unity B-splines. Required inequalities are

\[
\Theta_{i+1,h}\le\Theta_{i,h},\qquad
\Theta_{i,h+1}\ge\Theta_{i,h}.
\]

The standard derivative expansion is a positive knot-dependent coefficient times \((\Theta_{i+1,h}-\Theta_{i,h})\) times a nonnegative degree-\((d_x-1)\) basis; the \(Z\) derivative is analogous. Thus \(\partial g/\partial x\le0\) and \(\partial g/\partial Z\ge0\) over the continuous surface. This is a constraint on final \(\log_{10}M\), not on \(D\) or \(\Delta_{\rm P}\). No mixed-derivative sign constraint is allowed.

Use smooth raw parameters \(c_0,a_h,b_i,r_{ih},\log\lambda_x,\log\lambda_Z\), with \(\lambda_x,\lambda_Z>0\). Construct boundaries

\[
\Theta_{1,1}=c_0,\quad
\Theta_{1,h}=\Theta_{1,h-1}+\lambda_Z{\rm softplus}(a_h),\quad
\Theta_{i,1}=\Theta_{i-1,1}-\lambda_x{\rm softplus}(b_i).
\]

Traverse interior cells by increasing \(i+h\). With \(L_{ih}=\Theta_{i,h-1}\), \(U_{ih}=\Theta_{i-1,h}\), induction gives \(L_{ih}\le U_{ih}\), then

\[
\Theta_{ih}=L_{ih}+(U_{ih}-L_{ih}){\rm sigmoid}(r_{ih}).
\]

This is one scalar surface, not two independent derivative fields. Therefore mixed partials commute where smooth and integrations have no path dependence.

The sampled MLR vector is

\[
\boldsymbol\theta_M=
(c_0,\{a_h\},\{b_i\},\{r_{ih}\},\log\lambda_x,\log\lambda_Z,f_{\rm out}),
\]

unless solar-anchor center/scale is explicitly promoted. The exact raw-index ranges are \(h=2,\ldots,K_Z\) for \(a_h\), \(i=2,\ldots,K_x\) for \(b_i\), and \(i=2,\ldots,K_x,\ h=2,\ldots,K_Z\) for \(r_{ih}\). \(\Pi,\Theta,D,g,\Delta_*,\Delta_{\rm P}\) are deterministic derived quantities. Raw variables receive proper priors, for example

\[
c_0\sim\mathcal N(\mu_0,\tau_0^2),\quad
\log\lambda_x\sim\mathcal N(\mu_x,\tau_{\lambda x}^2),\quad
\log\lambda_Z\sim\mathcal N(\mu_Z,\tau_{\lambda Z}^2),
\]

\[
a_h,b_i,r_{ih}\sim\mathcal N(0,\tau_{\rm raw}^2)
\]

with all prior scales recorded in metadata. \(D_{ih}\) MUST NOT receive independent generative priors because it is derived. Use instead a shrinkage potential \(-\sum D_{ih}^2/(2\tau_D^2)\) and a full separate-scale quadratic smooth potential on

\[
D^{(2,x)}_{ih}=D_{i+1,h}-2D_{i,h}+D_{i-1,h},
\quad
D^{(2,Z)}_{ih}=D_{i,h+1}-2D_{i,h}+D_{i,h-1},
\]

\[
D^{(xZ)}_{ih}=D_{i+1,h+1}-D_{i+1,h}-D_{i,h+1}+D_{ih}.
\]

The valid difference domains are \(i=2,\ldots,K_x-1,\ h=1,\ldots,K_Z\) for \(D^{(2,x)}\), \(i=1,\ldots,K_x,\ h=2,\ldots,K_Z-1\) for \(D^{(2,Z)}\), and \(i=1,\ldots,K_x-1,\ h=1,\ldots,K_Z-1\) for \(D^{(xZ)}\). With separate positive scales \(\tau_x,\tau_Z,\tau_{xZ}\),

\[
\log\pi_{\rm smooth}
=-\frac12\sum_{i=2}^{K_x-1}\sum_{h=1}^{K_Z}
\left(\frac{D^{(2,x)}_{ih}}{\tau_x}\right)^2
-\frac12\sum_{i=1}^{K_x}\sum_{h=2}^{K_Z-1}
\left(\frac{D^{(2,Z)}_{ih}}{\tau_Z}\right)^2
-\frac12\sum_{i=1}^{K_x-1}\sum_{h=1}^{K_Z-1}
\left(\frac{D^{(xZ)}_{ih}}{\tau_{xZ}}\right)^2
+{\rm constant}.
\]

Unequal knot spacing MUST be accounted for in these differences; difference signs remain free. The solar anchor is \(g(x_\odot,Z_\odot)\sim\mathcal N(g_\odot,\sigma_\odot^2)\); exact centering is an optional stronger alternative and does not require \(\Delta_{\rm P}(x_\odot,Z_\odot)=0\).

For member \(k\), \(M_{jkq}=M_\odot10^{g(x_{jk},Z_q)}\), \(M_{{\rm tot},jq}=\sum_kM_{jkq}\), and \(f_{\rm out}\sim{\rm Beta}(3,12)\). Outlier \(\mu_{\rm out}=40,\sigma_{\rm out}=13\) are fixed. The initial candidate is \(K_x\times K_Z=8\times4\), giving \(K_xK_Z+3=35\) sampled scalars when all \(\tau\) values and the solar-anchor configuration are fixed hyperparameters; degrees and full knot vectors remain unresolved and MUST be chosen before implementation. T7’s \(f_0(x)+Zf_Z(x)\) is only a restricted prototype.

## Stage T8c: Rice likelihood and lookup

The dynamical statistic is \(u_j^{\rm obs}=\Delta v_{{\rm tan},j}\sqrt{r_{\perp,j}}\), where \(r_{\perp,j}\) is the physical projected separation expressed in AU, so \(u\) has units km s\(^{-1}\sqrt{\rm AU}\). The code variable \(\texttt{sep\_AU}_j\) is defined separately as the numerical value of \(r_{\perp,j}\) in AU. If \(u\) is not supplied directly,

\[
u_j^{\rm obs}=4.74\,\frac{\Delta\mu_j}{\varpi_j}\sqrt{\texttt{sep\_AU}_j},
\qquad
\sigma_{u,j}=u_j^{\rm obs}/({\rm dpm}/{\rm error})_j.
\]

Here \(\Delta\mu_j\) and \(\varpi_j\) are in mas yr\(^{-1}\) and mas, respectively; \(4.74\) is the km s\(^{-1}\) conversion factor, and \(({\rm dpm}/{\rm error})_j\) is dimensionless.

The fixed scale is \(s=\sqrt{M_{\rm tot}/M_\odot}\), so \(v=s\widetilde u\). The variables \(u,v,\widetilde u,\sigma_{u,j},\mu_{\rm out},\sigma_{\rm out}\) all use km s\(^{-1}\sqrt{\rm AU}\); \(p_c\) and all \(L\) terms are densities in the reciprocal unit. The Rice density has support \(u\ge0\), and \(\sigma_{u,j}>0\) is treated as the common Gaussian error scale of the two orthogonal components:

\[
R(u\mid v,\sigma)=\frac{u}{\sigma^2}
\exp[-(u^2+v^2)/(2\sigma^2)]I_0(uv/\sigma^2).
\]

For component \(c\),

\[
L_{c,j}(s)=\int_{\mathcal U_c}
R(u_j^{\rm obs}\mid s\widetilde u,\sigma_{u,j})
p_c(\widetilde u)\,d\widetilde u
\]

or

\[
L_{c,j}(s)=\int_{s\mathcal U_c}
R(u_j^{\rm obs}\mid v,\sigma_{u,j})
p_c(v/s)\,\frac{dv}{s}.
\]

The \(1/s\) Jacobian MUST be retained. \(L_j^{\rm mix}(s)=(1-f_{\rm out})L_{{\rm good},j}(s)+f_{\rm out}L_{{\rm out},j}(s)\).

The current good raw basis is

\[
p_{\rm good}^{\rm raw}(\widetilde u)=
A\widetilde u\exp[-B\widetilde u^2-\exp((\widetilde u-u_c)/C)]
\mathbf1[0<\widetilde u\le80],
\]

\[
A=5.434\times10^{-3},\quad B=2.544\times10^{-3},\quad
u_c=35.67,\quad C=3.100.
\]

Here \([\widetilde u]=[u]=[v]=[\sigma_u]=[\mu_{\rm out}]=[\sigma_{\rm out}]={\rm km\ s^{-1}\sqrt{AU}}\), so \([A]=[B]=[\widetilde u]^{-2}\) and \([u_c]=[C]=[\widetilde u]\); densities and likelihood terms have reciprocal units.

Its support integral is \(C_{\rm good}=0.9978600946\). The current implementation deliberately keeps this fixed raw basis, so the saved lookup uses a slightly non-normalized basis and \(f_{\rm out}\) is an effective likelihood weight rather than an exact generative outlier probability. It MUST NOT be silently renormalized in this implementation. Renormalization is a future model change requiring explicit approval, lookup rebuild, and revised interpretation.

Outlier is Gaussian truncated to \([0,U_{\rm out}]\):

\[
p_{\rm out}(\widetilde u)=
\frac{\phi((\widetilde u-\mu_{\rm out})/\sigma_{\rm out})}
{\sigma_{\rm out}C_{\rm out}}\mathbf1[0\le\widetilde u\le U_{\rm out}],
\]

\[
C_{\rm out}=\Phi((U_{\rm out}-\mu_{\rm out})/\sigma_{\rm out})
-\Phi(-\mu_{\rm out}/\sigma_{\rm out}),
\]

with fixed \(\mu_{\rm out}=40,\sigma_{\rm out}=13,U_{\rm out}=80\). Do not free these shape parameters in this window.

Precompute component log densities on a geometric scale grid \(0.25\le s_\ell\le2.5\), \(L_s=1024\), and interpolate linearly in raw \(s\). The current local window uses \(K=10\) observed \(\sigma_u\) and \(R=64\) Gauss–Legendre nodes. This is an approximation to the full \(v\in[0,\infty)\) integral because window tails are dropped; convergence against wider windows/reference integration is mandatory. Quick tests may use \(L_s=512\), but formal runs use 1024 after direct checks. Out-of-grid \(s\) MUST stop, not silently extrapolate. Use stable \(\log I_0\) evaluation. Grid, interpolation, normalization, data digest, row indices, nodes, support, and error checks MUST be metadata.

The exact current local bounds and Gauss–Legendre mapping are

\[
a_j=\max(0,u_j^{\rm obs}-K\sigma_{u,j}),\qquad
b_j=u_j^{\rm obs}+K\sigma_{u,j},
\]

\[
v_{jr}=\frac{a_j+b_j}{2}+\frac{b_j-a_j}{2}\xi_r,\qquad
w_{jr}=\frac{b_j-a_j}{2}\omega_r,
\]

where \(-1\le\xi_r\le1\) and \((\xi_r,\omega_r)\) are the standard \(R\)-node Gauss–Legendre nodes and weights. The implemented integrand is

\[
L_{c,j}(s)\approx\sum_{r=1}^{R}
w_{jr}R(u_j^{\rm obs}\mid v_{jr},\sigma_{u,j})
\frac1s p_c(v_{jr}/s)
\mathbf1[v_{jr}/s\in\mathcal U_c].
\]

This finite window is an approximation to the full \(v\in[0,\infty)\) integral because tails are dropped. The current \(K=10,R=64\) values require convergence checks; they are not universal model constants.

Lookup reuse is valid only when row indices, \(u_j^{\rm obs}\), and \(\sigma_{u,j}\) are identical in order and their combined digest matches, in addition to the Rice implementation, component bases, support/normalization, scale grid, quadrature, and interpolation convention. Any mismatch MUST stop reuse and trigger lookup reconstruction. For \(N\) systems, the current table build costs \(O(NL_sR)\), stores \(O(2NL_s)\) values for two dynamics components, and each MCMC evaluation costs approximately \(O(NQ)\) for interpolation and metallicity summation.

The final dynamics likelihood is

\[
\mathcal L_j^{\rm dyn}(\boldsymbol\theta_M)
=\sum_{q=1}^{Q}\overline P_{jq}
L_j^{\rm mix}(s_{jq}(\boldsymbol\theta_M)).
\]

This is the outer \(Z\) marginalization and MUST use saved \(\overline P_{jq}\) only.

For a legacy lookup using \([0,\infty)\) outlier normalization while integrating only \([0,80]\),

\[
C_{\rm old}=\Phi(40/13)=0.9989542536697612,\quad
C_{\rm new}=\Phi((80-40)/13)-\Phi(-40/13)=0.9979085073395224,
\]

\[
\ell_{\rm out,new}=\ell_{\rm out,old}
+0.0010473893812422,\qquad
\frac{C_{\rm old}}{C_{\rm new}}=1.0010479380850523.
\]

This is a one-time additive correction to old outlier log tables only. New tables MUST use \(C_{\rm new}\) directly and record normalization version plus migration-applied status; floors require a separate check.

## Scientific limitations

- This is modular/cut inference: dynamics does not update T8a global calibration parameters or \(\overline P_{jq}\), and shared calibration-induced cross-system covariance is not retained.
- Only the reported \(\sigma_{u,j}\) and saved \(\overline P_{jq}\) are propagated. \(M_G\), PARSEC age/model, colour/extinction-model, and fixed T6d plug-in uncertainty are not marginalized.
- The local Rice window is an approximation until wider-window/reference-integral convergence is demonstrated.
- The current raw good basis and effective \(f_{\rm out}\) semantics are implementation choices, not a claim of an exactly normalized generative mixture.
